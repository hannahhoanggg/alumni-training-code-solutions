# typescript-intro-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- When was TypeScript introduced?
  TypeScript was introduced in October 2012.
- Who created TypeScript?
  Microsoft created TypeScript.
- What does the TypeScript `Compiler` do?
  The TypeScript Compiler or tsc is responsible for taking our TypeScript code & compiling it into valid JavaScript so that the browser can read it.
- How can you compile TypeScript to JavaScript?
  TypeScript is JavaScript with syntax for types. You have to add syntax to our code that is explicit about the correct types of data being used throughout the application.
  TS allows the creation of types so that every property of an object or array can have an explicit data type associated with it. Being able to explicitly state the structure of objects & arrays is a huge advantage for code clarity & finding data errors.
- What are some benefits of using TypeScript?
  The huge benefit of using TypeScript is that it is easy to incrementally add TypeScript to an existing codebase, without having to do a total rewrite.
  TypeScript helps us guarantee that we are working with the correct data, makes the code more correct & much more robust, & even easier to read.
  It also helps us catch bugs & errors faster by providing a nice structured way of writing code.
